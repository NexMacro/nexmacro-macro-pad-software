# NexMacro Macro Pad Software

Official Windows configuration software for the NexMacro 12-key programmable macro pad.

NexMacro Macro Pad Software lets users configure shortcuts, profiles, icons, GIFs, RGB lighting, display layouts, dual rotary knobs, and live system stats for the NexMacro macro pad.

## Download

Download the latest Windows version from the Releases section of this repository.

## Features

- Configure the NexMacro 12-key macro pad
- Create custom macro profiles
- Assign keyboard shortcuts and app actions
- Customize display icons and GIFs
- Control RGB lighting
- Configure dual rotary knobs
- Display live system stats
- Save and switch workflow profiles

## Supported Device

NexMacro 12-key programmable macro pad with display and dual rotary knobs.

## Installation

1. Download the latest Windows ZIP file from Releases.
2. Extract the ZIP file.
3. Open the NexMacro software.
4. Connect your NexMacro macro pad with USB.
5. Start creating profiles, shortcuts, icons, GIFs, and display layouts.
